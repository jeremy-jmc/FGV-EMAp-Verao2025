# MCVRO C++ Project

## How to run

1. Download and locate the data in the `instancias` folder at the same level as `cpp_src`.

2. Change the variables `file_name` and `file_summary` in `main.cpp` to point to the desired input file and summary prefix.

3.  Navigate to the `cpp_src` directory:
    ```bash
    cd cpp_src
    ```

4.  Compile the project using make:
    ```bash
    make
    ```

5.  Run the executable:
    ```bash
    ./mcvro_run
    ```
